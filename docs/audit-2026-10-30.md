## 1. 范围

## 2. 方法

1. 全量单元测试（94 个）与 `compileall`。
2. 负面 CLI 测试：错误 token、缺快照、路径注入、错误参数。
3. 合规绕过测试：全角字符、空格、零宽字符、大小写、多空格。
4. 密钥与敏感信息扫描：token、`.env`、`sk-`、`Bearer`。
5. 真实店铺只读联调：`site check / products / supervisor / workshop / review`。
6. 发布只做 dry-run；真实写入路径用假站点单测覆盖。
7. 代码审查：路径拼接、异常处理、边界值、幂等、补偿。

## 5. 剩余风险（未修复）

| ID | 级别 | 风险 | 影响 | 建议 |
|---|---|---|---|---|
| RISK-01 | 高 | `publish --approve` 只是 CLI 布尔值，没有真实身份/审批令牌 | 能跑 CLI 的人就能发布 | 生产环境改为运营台登录 + 审批令牌 + 角色校验 |
| RISK-02 | 中 | 站点幂等键是“先执行后占位”，并发同 key 可能双写 | 重复发布/重复版本 | 改为“先占位再执行”或加分布式锁 |
| RISK-03 | 中 | 幂等键全局唯一，没有按 storeId 隔离 | 多租户可能串 key | 加 `storeId` 维度，唯一键改复合 |
| RISK-04 | 中 | 合规词库固定 `US` | DE/UK 规则差异未覆盖 | 按市场拆词库，review 传入 market |
| RISK-05 | 中 | 发布只针对最低价 SKU | 多 SKU 方案可能发错变体 | 方案增加目标 `variantId`，按变体发布 |
| RISK-06 | 中 | token 是静态环境变量，无轮换/过期 | 泄露后长期可用 | 增加 token 轮换、最小权限、过期时间 |
| RISK-07 | 中 | 诊断规则基于 30 个商品的小样本 | 阈值可能过拟合 | 样本扩大后回测，校准中位数/阈值 |
| RISK-08 | 低 | 工坊只生成英文 | 7 语站点只覆盖 1 种 | 接多语言模板或 LLM 翻译 |
| RISK-09 | 低 | 审查价格按最低价 SKU 的成本算 | 多 SKU 时底线可能算错 | 按目标 SKU 取成本 |
| RISK-10 | 低 | 快照包含商品与价格数据 | 本地文件泄露会暴露选品 | 静态加密/权限控制 |
| RISK-11 | 低 | 批量发布没有并发锁 | 多商品同时发可能互相覆盖 | 发布队列 + 商品级锁 |
